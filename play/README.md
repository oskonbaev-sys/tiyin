# Tiyin — материалы для Google Play Console

## Основное
- **Название:** Tiyin — учёт расходов
- **Пакет (applicationId):** `com.fr8masters.tiyin` — после первой публикации поменять нельзя.
- **Категория:** Финансы
- **Тип:** Приложение, бесплатное, без рекламы
- **Политика конфиденциальности:** https://tiyin.fr8mastersllc.com/privacy
- **Файл для загрузки:** `Tiyin-play.aab` из Releases → latest (полная версия с автозаписью, подписана ключом загрузки).

## Краткое описание (до 80 символов)
Учёт расходов: траты сами записываются из пушей банков, чеков и Telegram.

## Полное описание
Tiyin — простой учёт личных расходов и доходов в сомах.

Траты записываются сами:
• Автозапись из уведомлений банков и платёжных приложений — после покупки или перевода трата появляется в Tiyin без ручного ввода.
• Фото чека или скриншот перевода — AI распознаёт сумму, место и категорию, вы проверяете и сохраняете.
• Сообщение в Telegram-бот @tiyinplus_bot — напишите «такси 350», и трата записана.

Отчёты и контроль:
• Траты и доходы по категориям за день, неделю и месяц.
• Лимиты по категориям с предупреждением на 80% и 100%.
• Вопросы о своих тратах обычным языком во вкладке AI.

Конфиденциальность:
• Для автозаписи Tiyin читает только уведомления, в которых есть сумма; мессенджеры и почта не читаются.
• Доступ к уведомлениям включаете вы сами и можете выключить в любой момент.
• Без рекламы, данные не продаются и не передаются третьим лицам.

Вход — одноразовым кодом из Telegram-бота @tiyinplus_bot.

## Обоснование доступа к уведомлениям (если попросят в ревью / Permissions declaration)
Основная функция приложения — автоматический учёт расходов. Приложение использует NotificationListenerService, чтобы читать уведомления банковских и платёжных приложений о списаниях и поступлениях и записывать их как операции в личный учёт пользователя. Функция заявлена в описании в Google Play. Перед запросом доступа приложение показывает экран с объяснением, какие данные читаются и зачем; пользователь включает доступ сам в системных настройках и может отключить его. Обрабатываются только уведомления, содержащие денежную сумму; уведомления мессенджеров и почты игнорируются. Данные отправляются по HTTPS на сервер Tiyin только для ведения учёта пользователя и не передаются третьим лицам. Альтернатив с меньшим доступом нет: банки Кыргызстана не предоставляют открытого API для получения операций.

## Безопасность данных (Data safety) — ответы
- Собирает ли приложение данные: **Да**. Передаёт третьим лицам: **Нет** (Google Gemini — обработчик по поручению, не «передача»). Шифрование при передаче: **Да**. Можно запросить удаление: **Да** (в настройках «удалить всё»).
- **Личная информация → Имя:** собирается (из Telegram), функциональность приложения, обязательно.
- **Личная информация → Идентификаторы пользователя:** Telegram ID, функциональность и управление аккаунтом.
- **Финансовая информация → Другая финансовая информация:** суммы, получатели и категории операций; функциональность приложения.
- **Сообщения → Другие сообщения в приложении:** текст уведомлений банков с суммой (только при включённой автозаписи); функциональность, необязательно.
- **Фото и видео → Фото:** изображения чеков, загруженные пользователем; функциональность, необязательно; обрабатываются, не хранятся.
- **Сведения о приложении и производительности → Журналы сбоев:** нет (не собираем). Реклама/аналитика: нет.

## Остальные анкеты
- **Возрастной рейтинг:** опросник IARC → «Утилиты/продуктивность», насилия/азартных игр нет. Целевая аудитория: 18+.
- **Финансовые функции:** отметить «Учёт личных финансов / бюджет»; кредитов, платежей, криптовалюты нет.
- **Реклама:** нет. **Доступ для проверки (App access):** нужен вход. Дать ревьюеру инструкцию: «Отправьте /login боту @tiyinplus_bot в Telegram и введите код» — либо выдать тестовый код вручную перед отправкой на ревью (код живёт 10 минут; лучше договориться о постоянном тестовом входе).
- **Правительственные приложения / новости / COVID:** нет.

## Ключ загрузки
Подпись AAB — ключом загрузки `tiyin-upload` (сертификат SHA-256 `E8:AE:D6:B3:02:B6:EE:96:1C:6B:77:09:1E:FB:9C:B4:82:70:C8:A0:4F:EE:B6:3B:8A:C1:00:21:2C:86:E1:76`). В Play Console включить **Подписание приложений в Google Play** (Play App Signing): тогда Google хранит основной ключ, а потерянный ключ загрузки можно сбросить через поддержку.
Сам файл ключа и пароль в репозиторий не кладутся — они в секретах GitHub Actions (`TIYIN_KEYSTORE_B64`, `TIYIN_KEYSTORE_PASSWORD`, `TIYIN_KEY_ALIAS`).
